# Metaverse & Agentic AI: A Systematic Literature Review

This repository contains the replication package, search queries, screening logs, and analytical scripts for our systematic review on Agentic AI in the Metaverse.

## 📂 Repository Structure

- `01_search/`: Database search strings and raw metadata exports.
- `02_screening/`: Eligibility criteria (Inclusion/Exclusion) and screening logs.
- `03_extraction/`: Extracted data matrices and quality appraisal.
- `04_analysis/`: Data processing notebooks and analytical visualizations.
- `05_manuscript/`: Manuscript drafts, figures, tables, and BibTeX citations.
- `scripts/`: Utility scripts for deduplication and file normalization.

> **Note on PDFs:** Full-text PDF papers are excluded from this repository due to copyright restrictions.
